DEVICE DETECTION:
==================

Current Implementation (orientation.js, line 8-18):
  function isMobileDevice() {
    const hasTouch = 'ontouchstart' in window || navigator.maxTouchPoints > 0;
    const isSmallScreen = window.screen.width <= 1024;
    const mobilePattern = /Android|webOS|iPhone|iPad|iPod/i;
    return (hasTouch && isSmallScreen) || mobilePattern.test(navigator.userAgent);
  }

Issue: Not used in fullscreen.js! No mobile detection in fullscreen logic.
